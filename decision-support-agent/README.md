# decision-support-agent

פלאגין ל-Claude שהופך סוגיה עסקית למערכת תומכת החלטה עובדת: מודלים, דשבורד והמלצות מנומקות.
משלב ML קלאסי לנתונים טבלאיים עם Deep Learning לטקסט, תמונות ורצפים – רק כשזה מוצדק.

**מחברת:** Irena Spivak | SimplEctive

## זרימת העבודה (עם נקודת אישור אנושית)
1. **דיוק הסוגיה** – מי מחליט, מה, מתי, ומה מחיר הטעות. ❌ אישור
2. **דרישות נתונים** – חובה / משפר / נחמד, רמת פירוט והיקף.
3. **קליטת נתונים** – קבצים או מקור מחובר, מיפוי מול הדרישות, הסוואת מידע אישי.
4. **בדיקת נתונים** – איכות, דליפה, הטיות, יציבות. ❌ אישור
5. **ארכיטקטורה** – baseline → GBM → DL → שילוב, השוואה הוגנת על מדד עסקי. ❌ אישור
6. **בניית המערכת** – שכבת החלטה, הסברים, דשבורד, API, ניטור, model card.

כל שלב שומר פלט ממוספר ב-`work/` (01–05), כך שאפשר לעצור ולהמשיך בשיחה אחרת.

## דרישות Python
חובה: `pandas numpy scikit-learn pyarrow`
מומלץ: `lightgbm shap joblib`
אופציונלי: `sentence-transformers` (embeddings לטקסט, כולל עברית), `mlflow` (מעקב ניסויים), `fastapi uvicorn streamlit pyyaml` (מערכת).

```bash
pip install pandas numpy scikit-learn pyarrow lightgbm shap joblib
```

בלי LightGBM הסקריפט עובר ל-HistGradientBoosting; בלי SHAP – ל-permutation importance; בלי sentence-transformers – ל-TF-IDF+SVD. כל מעבר כזה מצוין בדוח.

## חיבורים (.mcp.json)
הקובץ הוא **תבנית** – החליפו את `<שרת-MCP-...>` בשרתים שאתם משתמשים בהם בפועל, או מחקו את הרשומה אם אינכם צריכים אותה (רשומה עם placeholder תופיע כשרת שנכשל בחיבור).
- משתמש מסד נתונים עם הרשאת **קריאה בלבד**.
- מפתחות רק במשתני סביבה (`DECISION_DB_READONLY_URL`, `ML_PROJECT_ID`).
- נתונים רגישים (רפואיים, פיננסיים) מעובדים רק בסביבה שאושרה לכך בארגון.

## בדיקת קבלה
הריצו על מאגר ציבורי שהתוצאות שלו מוכרות לכם (למשל סיכון אשראי), עם עמודת דליפה ששתלתם. בודקים שהסוכן:
- [ ] שאל על מחיר הטעות לפני שבחר מדד
- [ ] ניסח משפט סוגיה אחד ועצר לאישור

- [ ] זיהה משתנה דליפה ששתלתם מראש (למשל עמודה שנוצרה אחרי הכשל)
- [ ] הריץ baseline לפני כל מודל מורכב
- [ ] לא הפעיל Deep Learning על נתונים טבלאיים קטנים, ונימק זאת
- [ ] קבע סף החלטה לפי עלות, לא 0.5
- [ ] סט הבדיקה נגע רק בהשוואה הסופית
- [ ] כל המלצה במערכת מגיעה עם שלושה נימוקים ורמת ודאות
- [ ] נוצרו model card ודוח הטיות
