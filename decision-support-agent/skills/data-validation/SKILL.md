description: בדיקת איכות וכשירות נתונים למודל לפני אימון. טריגרים: "תבדוק את הנתונים", "הנתונים תקינים?".
---
1. הרץ את סקריפט הפרופיל על dataset.parquet:
   ```bash
   python "${CLAUDE_PLUGIN_ROOT}/skills/data-validation/scripts/profile_data.py" data/interim/dataset.parquet \
     --target <עמודת מטרה> --date-col <עמודת תאריך החלטה> --id-col <מזהה> \
     --group-cols <קבוצות לבדיקת הטיה> --text-cols <עמודות טקסט> \
     --out work/04_data_report.md
   ```
   (פרמטרים מגיעים מ-work/01_problem.md ו-work/02_data_requirements.md. אם יש עמודות שנרשמו אחרי רגע ההחלטה, העבר אותן ב-`--post-decision-cols`.)
2. בדוק ודווח לכל סעיף עבר/אזהרה/נכשל:
   - שלמות: אחוז חסרים לכל עמודה (אזהרה מעל 20%)
   - כפילויות ומזהים שאינם ייחודיים
   - ערכים בלתי אפשריים וקודים מיוחדים (999, -1)
   - איזון משתנה המטרה (אזהרה מתחת ל-5% במחלקה הקטנה)
   - דליפת מידע: משתנה שמתואם חשוד עם המטרה, או שנרשם אחרי רגע ההחלטה
   - יציבות לאורך זמן (PSI בין תקופות)
   - ייצוג קבוצות רלוונטיות לבדיקת הטיה
   - נתונים לא מובנים: קבצים פגומים, שפה, אורך טקסטים
3. ציון כשירות כולל: ירוק / צהוב (אפשר להמשיך עם הסתייגויות) / אדום (לא מאמנים).
4. הצע ניקוי לכל ממצא – אל תבצע ניקוי שמשנה משמעות בלי אישור.
   הסקריפט מסמן ממצאים; את הפרשנות העסקית (למשל: למה עמודה מסוימת היא דליפה) כתוב אתה, בשפה פשוטה, מעל הפלט הטכני.
5. פלט: work/04_data_report.md ועצירה לאישור.
