# מטריצת ארכיטקטורה

כלל האצבע: **סוג הנתונים קובע את המשפחה, והנפח קובע אם DL משתלם.**

| סוג נתונים | Baseline | ML | Deep Learning | שילוב מומלץ |
|---|---|---|---|---|
| טבלאי בלבד | כלל עסקי / רגרסיה לוגיסטית | XGBoost / LightGBM / CatBoost | רק במיליוני שורות (TabNet, MLP) | בדרך כלל ML בלבד |
| טבלאי + טקסט | מילות מפתח | GBM על המשתנים | מודל שפה מאומן מראש → embeddings | embeddings מהטקסט כמשתנים בתוך GBM |
| טבלאי + תמונות | – | GBM על המשתנים | CNN / Vision Transformer מאומן מראש | ציון התמונה מ-DL + GBM להחלטה |
| סדרות זמן | ערך קודם / ממוצע עונתי | GBM עם lags וממוצעים נעים | LSTM / Temporal CNN / Transformer לסדרות | ensemble של GBM ו-DL |
| רצף אירועים (קליקים, תנועות) | ספירות פשוטות | GBM על סיכומים | GRU / Transformer על הרצף | יציאת הרשת כמשתנה ל-GBM |
| חריגות בלי תיוג | ספים סטטיסטיים | Isolation Forest | Autoencoder | ציון משולב לתעדוף בדיקה |
| המלצה | הפופולרי ביותר | מטריצת פירוק / GBM לדירוג | Two-tower | שליפת מועמדים ב-DL + דירוג ב-GBM |

## כללי כניסה ל-DL
DL נכנס רק אם שלושתם מתקיימים:
1. הוא משפר את המדד העסקי בלפחות **2%** מול ML.
2. העלות החישובית (אימון + זמן תגובה) מוצדקת.
3. דרישת ההסבריות מהקנבס עדיין מתקיימת.

הסף של 2% הוא ברירת מחדל; קבעו סף משלכם לפי מחיר הטעות (`--min-gain`).

## מדדים לפי סוג משימה
| משימה | מדד עסקי | מדד טכני | כיול |
|---|---|---|---|
| סיווג | עלות כוללת = FP×עלות_FP + FN×עלות_FN | ROC-AUC, PR-AUC | Brier, ECE |
| רגרסיה / תחזית | עלות שגיאה בש"ח (או MAE ביחידות עסקיות) | MAE, RMSE, MAPE | כיסוי רווחי ניבוי |
| דירוג / המלצה | הכנסה/המרות ב-top-K שנבדקים בפועל | NDCG@K, Recall@K | – |
| חריגות | מקרים מאומתים ב-K הבדיקות הראשונות | Precision@K | – |

## מודלים מאומנים מראש (נקודת פתיחה)
- **טקסט עברית/רב-לשוני:** `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`, `intfloat/multilingual-e5-base`; לעברית ייעודית – מודלי BERT עבריים (למשל AlephBERT / HeBERT).
- **תמונות:** ResNet-50 / ViT-B/16 / CLIP – embeddings ואז GBM או ראש לינארי.
- **סדרות זמן:** מודלי יסוד לתחזית (Chronos / TimesFM) כ-baseline חזק לפני אימון LSTM.
