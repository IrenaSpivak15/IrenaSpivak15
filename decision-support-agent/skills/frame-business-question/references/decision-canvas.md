# קנבס סוגיה עסקית

הסוכן ממלא את כל השדות. שדה ריק = שאלה למשתמש.

- **ההחלטה:** מה בדיוק מחליטים? (פועל + אובייקט: "לאשר אשראי", "לפנות ללקוח")
- **מקבל ההחלטה:** מי, ובאיזה מסך/תהליך הוא עובד היום
- **רגע ההחלטה:** מתי, ומה ידוע ברגע הזה
- **תדירות ונפח:** כמה החלטות ביום/חודש
- **הפעולות האפשריות:** רשימה סגורה
- **שאלת החיזוי:** מה המודל צריך לחזות, באיזה אופק זמן
- **סוג המשימה:** סיווג / רגרסיה / דירוג / תחזית / חריגות / המלצה
- **מחיר הטעות:** עלות חיובי שגוי מול שלילי שגוי (בש"ח או יחס)
- **מדד הצלחה עסקי + המצב הקיים (baseline)**
- **מגבלות:** רגולציה, הסבריות נדרשת, זמן תגובה, פרטיות
