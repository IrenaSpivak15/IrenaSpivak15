# Ая и Серж: Сказка о горе и пути

Иллюстрированная сказка Ирены Спивак в виде веб-приложения, которым можно делиться.

- **Читалка**: листание (стрелки, свайп), оглавление, размер шрифта, темы день/сепия/ночь, чтение вслух.
- **Поделиться**: ссылка на всю книгу или на конкретную страницу (`#p1`…`#p9`), WhatsApp, Telegram, ВКонтакте, Facebook, почта, копирование ссылки.
- **Открытки-цитаты**: картинка с иллюстрацией и цитатой страницы (квадрат 1080×1350 или сторис 1080×1920).
- **Тест «Кто ты — Ая или Серж?»**: 6 вопросов и открытка с результатом (`#quiz`).
- **PWA**: можно установить на телефон, работает офлайн (`manifest.json`, `sw.js`).

Статический сайт, сборка не нужна: достаточно открыть папку через любой веб-сервер
(например, GitHub Pages) или локально:

```bash
python3 -m http.server -d aya-serge 8000
```
