# video-editor-agent

פלאגין ל-Claude: סוכן עריכת וידאו קצר לרשתות.

## זרימת עבודה
1. קליטת חומרים – תסריט וחומר גלם מיום הצילום.
2. חיתוך לפי תמלול – תמלול, חיתוך לפי תמלול ועוצמת קול, בחירת הטייק הטבעי ביותר.
3. עיצוב בסגנון מאושר – מסגור, כתוביות, צבע ואפקטים לפי מדריך הסגנון.
4. הגשת גרסה לאישור – גרסה ממוספרת, תיקונים בפורמט קבוע.
5. מחקר מתחרים – הצעת סגנון לבדיקת A/B, רק לאחר אישור.

## פקודות
- `/edit-video <תיקיית חומר> <שם פרויקט>` – מקצה לקצה עד גרסה לאישור
- `/revise <שם פרויקט> <תיקונים>` – תיקונים וגרסה חדשה
- `/research-style` – מחקר מתחרים והצעת סגנון B

## חיבורים
| חיבור | למה | איך |
|---|---|---|
| Google Drive | קליטת חומר גלם והעלאת גרסאות | המחבר המובנה של Claude |
| ffmpeg + ffprobe | חיתוך, עיצוב, רנדור | מותקן בסביבת העבודה |
| Whisper | תמלול עם חותמות זמן למילה | `pip install faster-whisper`, או MCP של שירות תמלול |
| חיפוש רשת | מחקר מתחרים | מובנה ב-Claude |

`.mcp.json` ריק כברירת מחדל. להוספת שרת תמלול חיצוני:
```json
{
  "mcpServers": {
    "transcription": {
      "command": "npx",
      "args": ["-y", "<שם-חבילת-התמלול>"],
      "env": { "API_KEY": "${TRANSCRIPTION_API_KEY}" }
    }
  }
}
```
אל תכניסו מפתחות API לפלאגין – רק משתני סביבה.

## אריזה והתקנה
```bash
cd video-editor-agent
zip -r ../video-editor-agent.plugin . -x "*.DS_Store"
```
ב-Claude: תפריט פלאגינים → "התקנה ידנית" / "Install from file" → להעלות את הקובץ. בשיחה חדשה להקליד `/edit-video`.
