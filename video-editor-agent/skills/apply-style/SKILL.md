1. קרא את `references/style-guide.md` לפני כל דבר.
2. מסגור: crop ל-9:16 וזום לפי המדריך.
3. כתוביות: צור קובץ ASS מהתמלול, עם הפונט, הצבע ומספר המילים מהמדריך. בדוק RTL.
4. צבע: החל את ה-LUT מ-`assets/`.
5. סאונד: נרמל ל-14 LUFS-, מוסיקה מתחת לדיבור לפי המדריך.
6. כל החלטה שלא מכוסה במדריך – רשום כשאלה בדוח, אל תמציא.
