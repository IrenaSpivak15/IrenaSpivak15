# מערכת תומכת החלטה - השקעה בנדל"ן בפורטוגל 🏠🇵🇹

כלי עזר (Decision Support System) ליזם ישראלי המעוניין להשוות, לדרג ולבחון נכסי מגורים
להשקעה בפורטוגל, על סמך קובץ CSV של רשימת נכסים.

## מה המערכת עושה

1. **טוענת ומנקה** קובץ CSV של נכסים לפי הסכימה למטה (טיפוסי נתונים, ערכים חסרים, בוליאנים).
2. **מחשבת ציון השקעה (0-100)** לכל נכס לפי שבעה מרכיבים משוקללים (ניתנים להתאמה ב-UI):
   - מחיר למ"ר יחסית לחציון המחוז
   - תשואת שכירות משוערת (ארוך טווח או Alojamento Local לפי בחירה)
   - איכות מיקום/רמת ביקוש אזורית
   - תעודת אנרגיה
   - מצב/גיל הבניין
   - מתקנים (מעלית, חניה, גראז', עמדת טעינה חשמלית)
   - יעילות שטח ביחס למספר החדרים
3. **מדרגת ומסננת** נכסים, עם תרשימים להשוואה בין מחוזות/ערים.
4. **מחשבון עלות רכישה ותשואה נטו**: מס רכישה (IMT), בול (Imposto de Selo), עו"ד/נוטריון/רישום,
   IMI שנתי והוצאות תפעול - כדי להגיע לתשואה נטו ריאלית ולא רק תשואה ברוטו.
5. מציגה **אזהרה מפורשת** שהשקעה בנדל"ן **אינה** מזכה עוד בויזת הזהב הפורטוגזית (מאז אוקטובר 2023).

> ⚠️ **הבהרה חשובה**: זהו כלי תמיכה בקבלת החלטות בלבד. שיעורי המס, התשואות האזוריות ומדרגות
> ה-IMT הם הערכות/ברירות מחדל אילוסטרטיביות הניתנות לעריכה, ואינן מהוות ייעוץ מס, משפטי או
> השקעות. יש לאמת כל נתון מול עו"ד, רואה חשבון ושמאי מקומיים בפורטוגל לפני קבלת החלטה.

## התקנה והרצה

```bash
cd portugal-dss
pip install -r requirements.txt
streamlit run app.py
```

לאחר ההרצה תיפתח כרטיסייה בדפדפן בכתובת `http://localhost:8501`.

## מבנה קובץ הקלט (CSV)

| עמודה | תיאור |
|---|---|
| `Price` | מחיר מבוקש באירו |
| `District`, `City`, `Town` | מיקום גיאוגרפי (מחוז / עיר / עיירה) |
| `Type` | סוג נכס (Apartment, House, Garage, Land...) |
| `EnergyCertificate` | תעודת אנרגיה (A+ עד G, או Isento/N/D) |
| `GrossPrivateArea`, `UsableArea`, `LivingArea`, `LotSize`, `BuiltArea` | מדדי שטח שונים |
| `Rooms`, `Bedrooms`, `Bathrooms`, `WCs` | פירוט חדרים |
| `Floor` | קומה |
| `Parking`, `Garage`, `Elevator`, `ElectricCarCharging` | מאפייני בוליאני/כן-לא |
| `ConstructionYear` | שנת בנייה |
| `PublishDate` | תאריך פרסום המודעה |

קובץ לדוגמה עם 60 נכסים סינתטיים על פני מגוון מחוזות נמצא ב-`data/sample_listings.csv`
(ניתן להשתמש בו כדי לבחון את הכלי לפני חיבור נתונים אמיתיים, למשל מ-Idealista/imovirtual/scraping).

## מבנה הקוד

```
portugal-dss/
├── app.py                 # אפליקציית Streamlit (UI, טאבים, תרשימים)
├── data/sample_listings.csv
├── dss/
│   ├── schema.py           # סכימת עמודות + ניקוי/נרמול נתונים
│   ├── regional_data.py    # פרופילי מחוז: רמת ביקוש, הנחות תשואה
│   ├── scoring.py          # מנוע הניקוד (7 מרכיבים -> ציון כולל + המלצה)
│   └── costs.py            # מחשבון IMT / בול / IMI / תשואה נטו
└── requirements.txt
```

## התאמה אישית

- **משקלי הניקוד** ניתנים לשינוי בזמן אמת מה-sidebar.
- **הנחות התשואה וההיטלים** ב-`dss/regional_data.py` ובטאב "מחשבון עלויות" ניתנות לעריכה
  ישירות ב-UI, ומומלץ לעדכן אותן לפי נתונים עדכניים לפני קבלת החלטה בפועל.
- ניתן להעלות כל קובץ CSV תואם-סכימה דרך ה-sidebar במקום קובץ הדוגמה.
